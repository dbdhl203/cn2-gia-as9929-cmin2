## “中国优化”优化的是哪一段路

服务器放在境外，但从国内访问时的路由被专门调整过，路径更短，晚高峰丢包更少。没有优化过的机器，数据包可能从上海出发先绕到日本、再经英国回美国，延迟直接翻倍。

主流线路大致分五档：

| 线路 | AS 号 | 大致定位 | 谁重点看 |
| --- | --- | --- | --- |
| CN2 GIA | AS4809 | 电信高端骨干，全程 GIA，丢包控制好 | 电信用户，对晚高峰稳定性有要求 |
| AS9929 | AS9929 | 联通精品骨干，定位与 CN2 GIA 接近 | 联通用户 |
| CMIN2 | AS58807 | 移动国际精品网，联通走这条也有不错表现 | 移动用户 |
| CMI | AS58453 | 移动国际线路，比 CMIN2 便宜一档 | 预算敏感的移动用户 |
| 163 / 4837 | AS4134 / AS4837 | 电信与联通的普通国际线路，晚高峰容易拥塞 | 不建议对稳定性有要求的人 |

匹配规则很直接：你主要用哪家宽带，就优先看那条线路。电信用户买一台回程只走 163 的机器，钱花了也拿不到 CN2 GIA 的体验；反过来，移动用户为 CN2 GIA 付溢价，多数时候用不上那份优势。

这里有个行业现状得说清楚。AS9929 和 CMIN2 这两条线在部分商家手里会因为成本或攻击临时切换路由，宣传页上写的线路和实际跑出来的线路不一定长期一致。对线路极其敏感的用途，选明确标注回程线路并且长期供应的那一档，别为了省一点钱在 EB 或入门款上赌。

## “中国优化”有可能只做一个方向

这是最容易被标题带过去的一点。有商家会明确说明：只优化洛杉矶到中国方向的回程，中国到洛杉矶的去程不做优化，带宽 100Mbps。这类产品在宣传上照样可以叫“中国优化”，因为它确实优化了一半。

这个差别对不同用途的影响完全不同。

面向国内用户的网站、API 服务、代理落地，数据主要从服务器流向用户，优化服务器到中国这一段就够用，去程不优化你基本感觉不到。反过来的场景就难受了：从国内往服务器推数据、跑远程备份、上传素材、做跨境办公的文件同步，走的是去程，没优化就是普通国际线路的水平。

所以看到“中国优化”三个字，正确的动作是问一句优化的是哪个方向，而不是默认双向都做了。条款里写了方向的，按方向判断是否匹配你的用途；没写的，就当它没承诺。

## 流量跑完之后会发生什么

三家商家的三种处理方式，实际体验差距比配置差距还大。

**降速不停机。** 超过月流量后切到限速模式，月初自动恢复。有商家把限速值写得很具体：香港和日本的小配置限到 50Mbps，洛杉矶的小配置限到 100Mbps。这个水平还能继续跑网站、看视频、传文件，只是慢一些。

**限速到几乎不可用。** 有商家的条款里写的是超量后限速 1Mbps。1Mbps 大约 128KB/s，SSH 操作还能忍，跑同步、拉镜像、传备份基本等于停摆。同一句话“超量限速”，实际含义差了两个数量级。

**直接关机或断网。** 低价套餐里常见。停机后要么等下个计费周期，要么临时加钱买流量包。

如果你跑的是定时任务、爬虫、监控、远程备份这类不看时间但必须跑完的活，第二种和第三种都会让你半夜起来处理。买之前把这条看明白，比多要 20GB 硬盘有用得多。

## IP 被墙之后，换一次要多少钱

被墙不是小概率意外，做这块业务的人早晚会碰到。处理规则各家不同，一套比较典型的条款是这样：购买满 7 天、距上次换 IP 超过 15 天、并且 ICMP 与全端口都被封，可以免费换一次；不满足条件按次收费，单次 5 美元，两次之间间隔不少于 7 天。

从这条规则能推出来两件实用的事：

新买的机器如果开箱就是被封状态，按上面这套条款是拿不到免费更换的，因为不满足“购买满 7 天”。有的商家会把“开箱 IP 可用”单独做成付费附加项，买之前确认一下有没有这个选项。

频繁换 IP 这条路走不通。15 天的间隔意味着一个月最多两次，靠换 IP 解决业务问题不现实，真要长期稳定还是得看线路本身的质量和用途是否合规。

## 月付还是年付：把第二年的账也算进去

年付通常比月付便宜一档，但便宜的部分往往只覆盖首期。判断方法很简单，在下单页把两个数字找出来：首期价格，以及续费价格。

如果续费价等于下单价，年付就是实打实的折扣，买长的划算。如果首页挂着大幅折扣而续费恢复原价，第二年成本会上跳，这时候用首年省下的钱去换一个可能不合适的机器，不划算。

再叠一层退款政策看。3 天内且流量使用不超过 30GB 全额退，是一个很常见的窗口，它实际上等于给你一个短期试用期。不确定线路在你所在城市表现如何，先买最小配置月付，跑满一个计费周期，把晚高峰的表现看清楚，再决定要不要转年付。这个顺序比反过来安全。

## 第一次登录卡住的地方

不少商家默认关闭密码登录，只发一个 `.pem` 密钥文件，而且这个文件只允许下载一次。流程大致是这样：

1. 付款后在控制台找到密钥下载入口，下载 `.pem` 并立刻另存两份，本地一份、网盘一份。
2. 在终端里改权限：`chmod 600 密钥文件路径`，权限不对会被拒绝。
3. 连接：`ssh -i 密钥文件路径 root@服务器IP`。
4. 想改回密码登录，在控制台重置 root 密码，然后编辑 `/etc/ssh/sshd_config`，把 `PasswordAuthentication` 改成 `yes`。
5. 重启 SSH 服务：`systemctl restart sshd`，再用密码登录验证一次。

第 1 步没做好，后面全得开工单。这不是危言耸听，密钥文件丢失后只能重置，重置过程中如果机器上有数据就得重装。

## 常见问题

**晚高峰会不会掉速？**

取决于线路档次和是否超售，没有统一答案。163 和 4837 这类普通线路在晚八点后拥塞最明显，丢包到两位数不罕见。CN2 GIA、AS9929、CMIN2 相对稳，但商家超售严重时照样会抖。验证办法是用商家公布的测试 IP，在晚上八点到十一点之间跑 `ping` 和 `mtr`，看丢包和跳数，白天测没意义。

**流量超了会直接断网吗？**

看商家的策略，三种都有：降速不停机、限速到极低值、直接关机。这条必须在下单前确认，不能默认。

**能不能退？**

看窗口。3 天内且流量不超过 30GB 全额退是比较常见的一档，超过这个范围有的商家按剩余价值退并扣支付通道费。免试用的商家不多，退款窗口就是你的试用期。

**香港机房为什么又贵又常缺货？**

物理距离近，到国内主要城市延迟能压到 20–50ms 这个区间，带宽成本比洛杉矶高出一大截，供给本身有限。做面向国内用户的站点，这个延迟差确实能感觉到；个人用途和流量不大的项目，洛杉矶档位够用，省下的钱能多买一两年。

**月付还是年付？**

先用月付最小配置跑一个完整计费周期，把晚高峰表现和实际用量摸清楚。确认稳定再转年付，前提是续费价不跳。
